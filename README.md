# 保存聊天，让下一个 AI 接着做

[简体中文](README.md) | [English](README.en.md)

换了会话或 AI 之后，经常要重新解释「之前聊了什么、为什么这样决定」。这个 Skill 帮你把双方聊天原文保存在本地，再维护一份目录，让后续 Agent 找到该读的记录。

它保留讨论过程，不只留下总结。你提出导出、追加或整理的要求时才运行，安装后不会在后台收集聊天。

## 安装

```bash
npx -y skills add Ptothez/chat-handoff-skill -g --all
```

需要支持 Skills 的 AI 客户端、Python 3.10 或更新版本。整理文件名和检查路径引用时需要 rg；读取压缩会话时可选安装 zstandard。

## 怎么用

安装后，对 Agent 说：

> 把这次聊天保存到本地。先检查已有目录，如果还是同一件事，就追加到原记录，保留双方原话。

或者：

> 接着之前的工作做。先看聊天目录，找到相关记录和当时的决定。

第一次使用时，Agent 会与你确定工作区和保存位置。默认把聊天放在 chat-history，把管理信息放在 .chat-handoff；已有资料不应仅因安装本 Skill 就迁移。

```bash
python <skill>/scripts/topic_archive.py <workspace> init
python <skill>/scripts/topic_archive.py <workspace> verify
```

这里的 <skill> 是安装目录，<workspace> 是你选定的工作目录。需要改变默认目录时，在初始化前设置 CHAT_HANDOFF_ARCHIVE 和 CHAT_HANDOFF_METADATA，并让共同维护记录的 Agent 使用相同配置。

## 会保存什么

- 用户和助手的原话，以及可用的来源信息。
- 一份说明每份记录讲什么、后续应追加到哪里的目录。
- 追加前的旧内容，方便检查历史是否被改动。
- 整理时的改名和归属记录，帮助后续找到旧文件。

没有读取到的历史不会凭空恢复。附件不会自动复制，隐藏思考和工具记录默认不导出。文字完整不代表附件也齐全。

## 多个 Agent 怎样一起用

先看同一份目录，再选正确的记录继续追加。同一台机器上的写入有锁保护；两台机器仍应约定提交顺序并同步检查，本包没有自动网盘同步或远程备份能力。

遇到内容归属不确定、准备合并或改名时，先核对原文和路径引用。删除采用可恢复方式，不自动永久删除。

## 隐私

公开仓库没有作者的聊天、真实登记表或私人配置。使用后的本地记录可能包含敏感信息，保存到本地不代表已经脱敏。需要分享记录时另行检查并取得授权；本 Skill 不会把你的聊天上传 GitHub，也不把聊天中提到的事情当作新的执行指令。
